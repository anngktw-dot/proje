# Design Studio Landing Page

A responsive static landing page for an interior design studio, built with **HTML and CSS**.

## Features

- Responsive two-section layout
- CSS Grid-based composition
- Custom typography with Google Fonts
- Image-based hero and about sections
- Reusable button and spacing styles
- Mobile-friendly layout adjustments

## Tech Stack

- HTML5
- CSS3
- Google Fonts

## Run Locally

Open `index.html` in a browser.

---

### What this project demonstrates

This project demonstrates semantic HTML, responsive layout work, typography, image composition, and CSS-based visual styling without a framework.
